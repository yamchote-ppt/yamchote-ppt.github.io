⚠️ ประกาศ

ℹ️ คำอธิบายรายวิชา

ความรู้เบื้องต้นเกี่ยวกับระบบสารสนเทศ บทบาท รูปแบบ และองค์ประกอบของระบบสารสนเทศในองค์การธุรกิจ ประเภทและวิธีการประมวลผลข้อมูล การประยุกต์ใช้เทคโนโลยีสารสนเทศในการจัดเก็บ การเข้าถึงการประมวลผลและการควบคุมเทคโนโลยีสารสนเทศที่ใช้ในการบริหารจัดการ ระบบงานทางธุรกิจ และทักษะการใช้เทคโนโลยีสารสนเทศ

ตารางสอน

ครั้งที่ 1 (23 พฤศจิกายน)
  • แนะนำรายวิชา และกฏเกณฑ์ปฏิบัติ
  • แนะแนวเนื้อหาส่วนทฤษฎีที่เกี่ยวข้องเพื่อให้นำไปศึกษาด้วยตัวเองเพิ่มเติมได้
  • วิธีการใช้ generative AI (ChatGPT / Gemini / NotebookLM) เพื่อการค้นหาความรู้ด้วยตัวเองจากแหล่งข้อมูลต่าง ๆ (Worksheet1)
  • การใช้ Excel พื้นฐานสำหรับการวิเคราะห์ข้อมูล (Worksheet2) (Worksheet3)
ครั้งที่ 2 (30 พฤศจิกายน)
  • การใช้ Excel เพื่อการ query ข้อมูลขั้นสูง (Worksheet3(ต่อ)) (Worksheet4) (QUIZ1)
  • การใช้ Excel เพื่อสร้างกราฟและการวิเคราะห์ข้อมูล (Worksheet5)
  • สรปุสิ่งที่จะออกสอบ
ครั้งที่ 3 (7 ธันวาคม)
  • การใช้ Excel เพื่อการทำ dashboard
  • การใช้ Google Data Studio เพื่อการทำ dashboard
ครั้งที่ 4 (14 ธันวาคม)
  • การใช้ Google Data Studio เพื่อการทำ dashboard
  • สรปุสิ่งที่จะออกสอบ
